# Face Lock Pro v3.0

Биометрическая система аутентификации на Python (FaceID + Liveness Check + Anti-Spoofing + Encrypted Data).

## 📌 О проекте

Этот проект — моя практическая работа для освоения компьютерного зрения (Computer Vision), биометрии, информационной безопасности и шифрования данных.

**Сразу говорю:** Я не заявляю, что это идеальная или на 100% готовенькая промышленная FaceID система. Я начинающий/обучающийся разработчик, и моя главная задача здесь — **практика, эксперименты и глубокое погружение в сферу**.

Код полностью открытый (Open Source) и бесплатный. Вы можете свободно использовать его, разбирать, модифицировать, оптимизировать под свои задачи или просто брать за основу. Единственное условие — указывать авторство (**Terorating**), если используете мой код или ключевые идеи. Это базовое уважение к чужому труду.

## 🚀 Основные возможности (v3.0)

* **Сетка лица (Face Mesh):** Построение и отслеживание 468 ключевых точек лица через MediaPipe.
* **Шифрование данных (`CryptoManager`):** Биометрический слепок не хранится в открытом JSON. Данные шифруются с использованием PBKDF2 (SHA-256) и динамического ключа устройства.
* **Защита от фото и видео (Liveness Check):** Проверка динамики в реальном времени (моргание через EAR, улыбка, повороты головы) + интерактивные челленджи.
* **Детекция индивидуальных особенностей (`MoleDetector`):** Поиск и сверка родинок/шрамов на лице для дополнительной защиты.
* **Анализ артикуляции (`LipMovementDetector`):** Проверка движения губ и речи для отсечения дипфейков и статических масок.
* **Анти-спуфинг (`AntiSpoofing`):** Детекция повторных атак по хэшам кадров (Replay Attack) + первичный анализ плотности градиентов.
* **Безопасная блокировка (`SafeBlockInput`):** Блокировка ввода с фоновым потоком-наблюдателем (Watchdog), который автоматически снимает замок через 30 секунд при сбое программы.

## ⚙️ Разбор настроек (`config.json`)

Все параметры вынесены в `config.json`:

### 1. `camera` (Настройки камеры)
* `device_id`: Индекс веб-камеры (по умолчанию `0`).
* `width` / `height`: Разрешение видеопотока (`640x480`).
* `fps`: Частота кадров (`30`).

### 2. `detection` (Детекция)
* `confidence_threshold`: Минимальный порог уверенности модели в детекции лица.
* `mole_min_area` / `mole_max_area`: Ограничения размера родинок/шрамов (в пикселях).
* `mole_contrast_threshold`: Порог контраста для отделения темных точек от кожи.
* `mole_match_threshold`: Коэффициент совпадения родинок для подтверждения личности.
* `lip_movement_threshold`: Чувствительность детектора движения губ.

### 3. `liveness` (Проверка «живости»)
* `timeout`: Время (в секундах), отведенное на первичную проверку живости.
* `liveness_threshold`: Порог итогового балла, выше которого человек признается «живым» (по умолчанию `0.55`).
* `blink_weight` / `lip_weight` / `mole_weight`: Весовые коэффициенты каждого фактора в итоговой оценке.
* `challenge_timeout`: Время на выполнение случайной команды (улыбнуться, повернуть голову и т.д.).

### 4. `security` (Безопасность)
* `block_watchdog_timeout`: Максимальное время непрерывной блокировки `BlockInput`. Гарантирует разблокировку мыши и клавы при сбое.
* `encryption_iterations`: Количество итераций PBKDF2 при генерации ключа шифрования.

## 🛠 Быстрый запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Terorating/FaceID-Liveness-Security.git
   cd FaceID-Liveness-Security
   ```

2. **Установите зависимости:**
   ```bash
   pip install opencv-python mediapipe numpy cryptography
   ```

3. **Загрузите модели MediaPipe:**
   Поместите следующие файлы моделей в папку `models/`:
   * `face_landmarker.task`
   * `hand_landmarker.task`

4. **Запустите программу:**
   ```bash
   python main.py
   ```
