Что оно вообще умеет (и что поменялось)
Я недавно полностью переписал ядро. Это не просто патч — я с нуля переделал логику безопасности и проверки живости. Вот что делает текущая версия:

Сетка лица: Строит 128 ключевых точек через MediaPipe для сравнения.

Защита от фото (починено): Теперь реально работает. Система заставляет тебя моргнуть (через EAR с нормальным гистерезисом) или улыбнуться, чтобы доказать, что ты живой. Фотки больше не проходят.

Настоящее шифрование: Я выкинул старую XOR-обфускацию. Теперь биометрия шифруется через Fernet (AES) и привязывается к твоей учетке Windows через DPAPI. Если кто-то украдет папку data и откроет на другом компе — там будет просто мусор.

Нормировка расстояний: Сравнение лица больше не ломается, если ты подошел ближе или отошел дальше от камеры. Расстояния нормализуются по ширине лица.

Защита от перебора: Если кто-то 5 раз попытается подделать лицо, система блокирует вход на 5 минут.

Блокировка: Если включить режим блока, мышь и клава отрубаются. Но там есть таймер-предохранитель (Watchdog), чтобы если прога крашнется, ты не остался с заблокированным компом навсегда.

(Примечание: Детекция родинок и движения губ из старой v3.0 временно отключена, пока я стабилизирую ядро. Планирую вернуть их позже).

Как запустить
Клонируй репо:
git clone https://github.com/Terorating/FaceID-Liveness-Security.git

Поставь зависимости:
pip install opencv-python mediapipe numpy cryptography pywin32

Скачай модели MediaPipe (face_landmarker.task и hand_landmarker.task) и закинь их в папку models/.

Запусти:
python main.py

Настройки
Пока все параметры лежат прямо в коде. Если не знаешь, что делает параметр — лучше не трогай, я предупредил. (В следующем обновлении вынесу всё в config.json).
